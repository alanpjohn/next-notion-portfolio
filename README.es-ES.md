## Scripts Disponibles

### Ejecutar el servidor de desarrollo.

```bash
    npm run dev
```

### Compilar para producción.

```bash
    npm run build:analyze
```

### Ejecutar el servidor de producción.

```bash
    npm run start
```

### Analizar el código con Lint

```bash
    npm run lint
    npm run lint:style
```

## Aprender Más

Para aprender más sobre **superplate**, consulta la [Documentación](https://github.com/pankod/superplate).

### **NextJS**

Un framework de React para producción con todas las características que necesitas: renderizado híbrido estático y del lado del servidor, soporte para TypeScript, agrupación inteligente, precarga de rutas y más. 

[Ir a la Documentación](https://nextjs.org/docs)

### **Notion API**

Permite conectarse a bases de datos de Notion, dándote el poder de usar Notion como un CMS.

[Ir a la Documentación](https://developers.notion.com/docs)

### **TailwindCSS**

Un framework CSS utility-first lleno de clases como flex, pt-4, text-center y rotate-90 que pueden componerse para crear cualquier diseño, directamente en tu marcado.

[Ir a la Documentación](https://tailwindcss.com/docs)


### **SASS/SCSS**

Sass es un lenguaje de hojas de estilo que se compila a CSS. Te permite usar variables, reglas anidadas, mixins, funciones y más, todo con una sintaxis totalmente compatible con CSS.

[Ir a la Documentación](https://sass-lang.com/documentation)


### **Variables de Entorno**

Usa variables de entorno en tu proyecto de next.js para el lado del servidor, del cliente o ambos.

[Ir a la Documentación](https://github.com/vercel/next.js/tree/canary/examples/environment-variables)


### **Analizador de Paquetes (Bundle Analyzer)**

Usa webpack-bundle-analyzer en tu proyecto de Next.js. Visualiza el tamaño de los archivos de salida de webpack con un mapa de árbol interactivo y ampliable.

[Ir a la Documentación](https://github.com/vercel/next.js/tree/canary/packages/next-bundle-analyzer)


### **ESLint**

Una herramienta de linting configurable y extensible para identificar y reportar patrones en JavaScript. Mantén la calidad de tu código con facilidad.

[Ir a la Documentación](https://eslint.org/docs/user-guide/getting-started)


### **Prettier**

Un formateador de código con opiniones propias; Soporta muchos lenguajes; Se integra con la mayoría de los editores.

[Ir a la Documentación](https://prettier.io/docs/en/index.html)
